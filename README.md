# My Characters Library Studio — Versions officielles

Ce dépôt distribue les **installateurs Windows** et les **mises à jour** de My Characters Library Studio.

➡️ [Télécharger la dernière version](https://github.com/Azashiin/my-characters-library-releases/releases/latest)

➡️ [Découvrir la communauté](https://my-characters-library-albui.asashiin.chatgpt.site)

## Installation

Téléchargez le fichier `.exe` de la dernière version, fermez le Studio puis lancez l’installateur. Vos créations et votre bibliothèque locale sont conservées.

À partir de Studio 3.7, les mises à jour se trouvent dans **Paramètres & cadres → Mises à jour du Studio**. Le logiciel recherche les nouvelles versions au démarrage et vous laisse choisir quand les télécharger et les installer.

## Fichiers des versions

- `.exe` : installateur Windows 64 bits.
- `.sha256` : empreinte de contrôle du programme.
- `studio-update.json` : présentation de la version, signée pour le logiciel.

Ce dépôt contient uniquement la distribution et ses notes de version. Le code de l’application et les données des utilisateurs n’y sont pas publiés.
